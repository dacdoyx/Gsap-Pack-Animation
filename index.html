01 — Page Load
Elastic Bounce In
Element enters from below with elastic ease. Perfect for cards, modals, CTAs.
// Elastic Bounce In gsap.from(element, { y: 60, opacity: 0, scale: 0.8, duration: 0.8, ease: "elastic.out(1, 0.5)" });
02 — Stagger
Stagger Grid Entrance
Multiple items animate in with cascading delay. Great for grids and lists.
// Stagger Grid Entrance gsap.from(".item", { y: 30, opacity: 0, scale: 0.9, duration: 0.5, stagger: 0.08, ease: "power3.out" });
03 — Text
Character Split Reveal
Each character cascades in from below. Ideal for headlines and hero text.
HELLO
// Character Split Reveal gsap.from(".char", { y: 40, opacity: 0, rotateX: -90, duration: 0.6, stagger: 0.04, ease: "back.out(2)", transformOrigin: "top center" });
04 — Counter
Animated Counter
Numbers count up smoothly on scroll. Perfect for stats sections.
000
// Animated Counter const obj = { val: 0 }; gsap.to(obj, { val: 100, duration: 2, ease: "power2.out", onUpdate: () => { el.textContent = Math.round(obj.val) .toString() .padStart(3, "0"); } });
05 — Reveal
Wipe Clip Reveal
A color wipe uncovers the element underneath. Cinematic and clean.
// Wipe Clip Reveal const tl = gsap.timeline(); tl.to(wipe, { scaleX: 1, duration: 0.5, ease: "power3.inOut" }).to(wipe, { scaleX: 0, transformOrigin: "right", duration: 0.5, ease: "power3.inOut" });
06 — Loop
Infinite Float
Gentle floating loop animation. Great for illustrations and UI accents.
// Infinite Float gsap.to(element, { y: -14, duration: 2.2, ease: "sine.inOut", repeat: -1, yoyo: true });
07 — Interaction
Particle Burst
Particles explode outward on trigger. Use on clicks or milestone events.
// Particle Burst for (let i = 0; i < 12; i++) { const angle = (i / 12) * Math.PI * 2; const dist = 50 + Math.random() * 30; gsap.to(particles[i], { x: Math.cos(angle) * dist, y: Math.sin(angle) * dist, opacity: 0, scale: 0, duration: 0.8, ease: "power2.out" }); }
08 — Scroll
ScrollTrigger Fade Up
Elements animate in as they enter the viewport. The classic scroll pattern.
// ScrollTrigger Fade Up gsap.from(".section", { y: 50, opacity: 0, duration: 0.9, ease: "power3.out", scrollTrigger: { trigger: ".section", start: "top 85%" } });
09 — Morph
Shape Morph
Border-radius morphs between shapes with fluid ease. Organic & eye-catching.
// Shape Morph gsap.to(element, { borderRadius: "50%", rotate: 180, scale: 1.2, duration: 0.9, ease: "power2.inOut", yoyo: true, repeat: 1 });
10 — Text
Typewriter Effect
Text types itself out letter by letter. A classic attention-grabber for hero sections.
// Typewriter Effect const text = "Hello World_"; const obj = { len: 0 }; gsap.to(obj, { len: text.length, duration: 1.8, ease: "none", onUpdate: () => { el.textContent = text.slice( 0, Math.round(obj.len) ); } });
11 — Line
Line Draw Expand
A line expands from the center outward. Clean divider animation.
// Line Draw Expand gsap.from(line, { scaleX: 0, transformOrigin: "center", opacity: 0, duration: 1, ease: "expo.out" });
12 — Loader
Dot Pulse Loader
Three dots pulse in sequence. The go-to loading state animation.
// Dot Pulse Loader gsap.to(".dot", { y: -12, duration: 0.4, ease: "power2.out", stagger: { each: 0.15, repeat: -1, yoyo: true } });
